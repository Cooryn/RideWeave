# 🚴 RideWeave

> 把每一次出发，织成自己的骑行版图。

RideWeave 是一款 Windows 个人骑行轨迹管理应用。把 GPX 文件拖进来，就能在地图上回顾路线、看看常骑的道路，再用图表和统计发现自己的骑行节奏。

**本地保存 · 无需账户 · 浅色 / 深色主题**

## 能做什么？

- **攒一张自己的骑行地图**：把多次骑行叠在一起，看看去过哪里，还有哪些路值得探索。
- **发现常骑路线**：切换到骑行热区，用颜色看出道路经过次数，熟悉的通勤路也有自己的存在感。
- **回看一次出发**：查看距离、经过时间、平均速度，以及速度和海拔变化；图表与地图位置同步联动。
- **一键回放轨迹**：用不超过 20 秒重温整段骑行，随时暂停、拖动进度，停在想看的地方。
- **看看最近骑得怎么样**：里程趋势、骑行频率、活跃天数和个人纪录，集中在数据统计页。
- **整理自己的记录**：批量导入、自动去重、修改名称、隐藏路线或删除记录，轨迹和原始 GPX 都保存在本机。

## 三步开始，点亮第一条路线

### 1. 安装并打开

前往 [下载页面](https://github.com/Cooryn/RideWeave/releases/latest)，下载 Windows x64 安装包（文件名以 `x64-setup.exe` 结尾），安装后打开 RideWeave。

安装时如提示缺少 WebView2，按提示联网安装即可。第一次打开没有骑行记录？很正常，版图等你亲自点亮。

### 2. 导入 GPX

点击右上角的 **“导入 GPX”**，或直接把文件从资源管理器拖进应用窗口，在哪个页面都可以。

- 支持一次导入多个文件，文件选择时可按 `Ctrl` / `Shift` 多选，每个文件不超过 **50 MB**。
- 导入后会显示新增、重复和失败数量；有文件失败时可以展开查看原因，其他文件仍会继续导入。
- 相同轨迹会自动跳过，即使改过文件名也不用担心重复导入；同一路线在不同日期的骑行会分别保留。
- 导入不会移动或修改源文件。

使用 Apple 健康的骑行记录？先导出并解压数据，找到 `workout-routes` 目录中的 GPX，再挑选骑行文件导入。当前只读取 GPX，不直接读取 ZIP 或健康 XML，也不会自动筛选运动类型。

### 3. 在地图上逛逛

导入完成后，打开 **“骑行地图”**，在地图上切换两种视角：

| 模式     | 看什么                                                             |
| -------- | ------------------------------------------------------------------ |
| 骑行路线 | 按原始 GPS 位置展示每次骑行，适合回顾具体路线。                    |
| 骑行热区 | 将匹配到的道路归并居中，按经过次数显示颜色渐变，看看哪些路最常骑。 |

点击路线或右侧记录就能打开详情。记录旁的眼睛按钮可以隐藏或显示路线；想重新看全貌，点击 **“全部轨迹”**，即可恢复所有路线并让地图显示完整范围。

热区里的往返和重复经过会分别计数。同一条骑行中识别出的暂停缺口会自动补连，优先沿道路连接，道路不可用时在骑行路线中直接连接两端。道路匹配和补连是地图展示用的估算，不会改动原始 GPX、里程或时间统计。

## 回味一趟骑行

在骑行详情里，除了距离、经过时间和平均速度，还能查看速度图；GPX 有有效海拔时，也会显示海拔图和估算的累计爬升。

- **指哪看哪**：鼠标悬停在图表上，可查看附近采样点的时间、速度和海拔，地图上的圆点同步标出位置。
- **动起来看**：点击 **“播放”**，整段轨迹会在最多 20 秒内回放；可以暂停、拖动进度条，结束后再次点击即可重播。
- **边播放边查看**：悬停图表只预览鼠标所在位置，不会改变播放进度或暂停状态；移开后回到当前回放位置。
- **也能用键盘**：聚焦图表后，用 `←` / `→` 逐点预览，`Home` / `End` 跳到起终点，`Esc` 退出预览。

进度条下方的数值跟随回放位置，悬停提示显示鼠标预览位置的数据。没有采样的缺口不会补造图表数据或回放位置。

## 看看自己的骑行节奏

进入 **“数据统计”**，选择 **近30天 / 今年 / 全部**，看看最近的积累：

- **总览**：里程、次数、活跃天数、累计时间，以及平均单次距离、综合均速和最长连续骑行天数。
- **趋势**：在里程与次数之间切换，悬停柱条查看对应时段的数据。
- **分布**：看看自己常在哪天出门、每次通常骑多远。
- **单次纪录**：找到骑得最远、用时最长和均速最快的一次，点击即可回到对应路线。

统计包含所选时间范围内的全部已保存记录，不受地图路线显隐影响。近30天包含今天，跨午夜的骑行按出发日归类；更详细的计算口径可以在看板底部展开查看。

## 给记录起个好名字

在骑行详情里点击 **“修改名称”**，把默认名称换成“周末追风”或“下班绕远一点”，下次回看更有画面感。

**“历史记录”** 页面可以浏览全部骑行。最近骑行、历史列表和详情中的删除按钮都会先让你确认；删除后，应用里的轨迹、保存的原始 GPX 和相关统计会一起更新，电脑上原来的源文件仍会保留。

喜欢白天清爽、晚上沉浸？点击标题栏的太阳 / 月亮按钮，或在 **“设置 → 外观”** 切换浅色与深色，应用会记住你的选择。

## 数据放在哪？怎么备份？

骑行记录、轨迹点和导入的原始 GPX 保存在本机，关闭后重新打开会自动加载，无需登录或云同步。

Windows 数据文件位置：

```text
%APPDATA%\com.rideweave.desktop\rideweave.db
```

备份时先退出 RideWeave，再复制整个 `com.rideweave.desktop` 文件夹；同目录下的数据库附属文件也要一起保留。设置页的 **“本地数据 → 数据位置与备份”** 随时可以找到这份说明。

## 几个使用小贴士

- **地图需要联网，记录留在本机。** 底图由 OpenFreeMap 提供，基于 OpenStreetMap 数据，无需填写地图 Key。地图服务会收到所查看区域的资源请求，原始 GPX 和轨迹时间不会上传。
- **断网也能整理骑行。** 仍可导入、查看和管理本地记录；底图无法加载时会使用纯背景，骑行路线仍可查看。当前不提供离线底图库下载。
- **平均速度包含停留。** 平均速度按轨迹距离除以首尾经过时间计算，休息时间也算在内，与设备上的移动均速可能不同。
- **缺失数据就留空。** 时间不完整时不计算经过时间和均速；没有有效海拔时隐藏海拔相关内容。速度图在缺少原始速度时会尝试使用连续采样点估算，并标注“含估算”。
- **导入已有记录，慢慢攒版图。** 当前通过 GPX 文件导入，不提供实时定位、Apple 健康自动同步或账户云同步。
